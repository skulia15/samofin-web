Copy drawings from Autodesk Forma to SharePoint automatically

Samofin Connector copies new drawings, models and documents from Forma Data Management (formerly Autodesk Docs) to a document library on your SharePoint site. Each new revision is added as a new version of the existing file, so everyone who opens the library sees the current revision. This page explains what the connector can access in Microsoft 365 and what your administrator does to set it up.

What the connector can access in Microsoft 365

One site only
The connector asks Microsoft for the Sites.Selected permission, which grants nothing on its own. Your administrator then gives it write access to one site. It cannot see your other sites, mail, Teams or users.
No passwords
The connector signs in with a certificate held by Samofin. No user account or password is shared with us.
Nothing is deleted
The connector creates folders, uploads files and adds new versions. It never deletes, moves or renames anything in SharePoint, even when a file is deleted in Autodesk.
Access can be removed
Your administrator can remove the connector’s access at any time. Copying stops immediately, and files already copied stay where they are.
Hosted in the EU
Files pass through Samofin’s servers on Google Cloud in Finland and are not stored there.

Setup takes your administrator about 15 minutes

Setup is done by a Global Administrator or Privileged Role Administrator of your Microsoft 365 tenant. We send the consent link and the exact commands.

  1. 1ApproveOpen the consent link we send and sign in. Check that the app is Samofin Connector and that the permission is “Access selected site collections”, then accept.
  2. 2GrantGive the connector write access to the chosen site, with one request in Graph Explorer or one PnP PowerShell command.
  3. 3CheckCheck the document library’s settings, which are listed in the next section.
  4. 4SendSend us the site URL, the library name and your tenant ID. We run a read-only check and confirm with you before anything is copied.

Document library settings to check

We recommend a library used only for these files, so people know it is kept up to date automatically. If people only need to read the files, give them read access to the library. The connector is then the only one that writes to it, which suits an archive or handover copy.

Versioning
Create major versions. Minor versions are drafts, so readers would not see new revisions.
Content approval
Turn content approval off. Otherwise each new revision waits for approval before others can see it.
Check-out
Do not require check-out. If it must stay on, tell us, and the connector checks in each file it uploads.
Required columns
Make sure no column is required. A required column without a value keeps uploaded files checked out and hidden from others.

Questions and answers

Is this two-way sync?
The connector copies in one direction only, from Autodesk to SharePoint. Changes made in SharePoint are not sent back to Autodesk.
What happens when a file is deleted in Autodesk?
The file stays in SharePoint, and the connector flags it for you to review.
Are long folder paths a problem?
SharePoint allows at most 400 characters in a file’s full path. If Autodesk folders are nested so deeply that a path would be longer, the connector skips those files and records each one in the log.
Can access be limited to one document library?
The connector can be limited to a single document library instead of the whole site. Tell us before setup, and we send the commands for that instead.
How do we remove access?
Remove the connector’s site permission in Graph Explorer, or delete Samofin Connector under Enterprise applications in the Microsoft Entra admin center. Either one stops all copying immediately, and files already copied stay where they are.
