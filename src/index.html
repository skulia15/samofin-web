Keep Procore, AjourBox and SharePoint up to date with Autodesk Forma

Samofin Connector copies new drawings, models and documents from Forma Data Management (formerly Autodesk Docs) to the system your site team uses. Designers keep working in Forma as they do today, and the site team sees each new revision in its own system without anyone downloading and uploading files.

When files are copied by hand, the site falls behind

Architects and engineers publish their drawings in Forma Data Management. Contractors, however, run site work and quality control in Procore, AjourBox or SharePoint. Someone has to copy each revision from one system to the other. It is repetitive work, and a single missed revision can mean building from an outdated drawing.

After setup, new revisions are copied automatically

  1. 1ConnectYour Autodesk administrator gives Samofin Connector read-only access as a custom integration.
  2. 2Link foldersWe work with you to decide which Autodesk folders go to which folders in your site system.
  3. 3ReviewBefore anything is copied, you see a test run that lists every file the connector will create.
  4. 4SyncFrom then on, the connector copies each new revision automatically and records it in the log.

Every revision goes to the matching folder

Each folder in Forma Data Management is linked to a folder in your site system. When a file changes, the connector copies the new version to the linked folder, and the log records which version went where and when.

How your data is handled

Read-only in Autodesk
The connector reads from Forma Data Management and never writes to it.
Nothing is deleted
The connector does not delete files in your site system. If a file is removed in Autodesk, the connector flags it for you to review.
Full version history
Each revision is added as a new version of the existing file, so the file’s history stays in one place.
Complete log
Every copy is recorded: which file and version, when, and where it went. Log entries cannot be changed.
No file storage
Files pass straight from Autodesk to your site system, and the connector does not keep a copy. Only the log is stored.
Hosted in the EU
The connector runs on Google Cloud in Finland, so project data stays under EU data-protection law.

Questions and answers

Which file types can it copy?
The connector copies every file in a linked folder unchanged, whatever its type, including PDF, DWG, IFC, RVT and Office files.
How quickly do new revisions appear?
New revisions appear within an hour. By default, the connector checks linked folders for changes every 15 minutes.
What access does it need?
In Autodesk, it needs read-only access to Forma Data Management. Your Autodesk administrator grants this as a custom integration. In your site system, it uses its own service account, limited to the projects or sites you choose. It never writes to Autodesk and never deletes anything.
How long does setup take?
Setup takes a week at most. We link the folders with you and you review a test run. After that, the connector runs alongside your current process for one to two weeks before you switch over.
What happens when a drawing is revised?
The connector adds the new revision as a new version of the existing file in your site system, so its history is kept and nothing is duplicated. It never removes older versions. If a file is renamed or moved, the connector follows it instead of uploading it again.
Which systems does it support?
The source is Forma Data Management (formerly Autodesk Docs, part of Autodesk Construction Cloud). The connector copies to Procore, AjourBox and SharePoint, and one Autodesk project can send to several of them at once. How the connector works with SharePoint
