Samofin Connector copies new drawings and documents from Autodesk Docs to Procore, AjourBox and SharePoint.

You choose which folders to follow. Each new version is copied to the matching folder in your site system and logged.

Every revision is copied by hand.

Architects and engineers publish in Autodesk Docs, part of Autodesk Construction Cloud (ACC). Owners increasingly require it as the project web. Contractors run site work and quality control in other systems. Someone copies every new revision across by hand, and outdated drawings end up on site.

One source, several targets.

  1. 1ConnectYour admin authorises read access to the project in Autodesk Docs.
  2. 2MapChoose which folders sync to which folders in your system.
  3. 3SyncNew versions are copied automatically, and every copy is logged.

What the connector does and does not do.

One-way
Reads from the source, never writes to it.
Never deletes
Removed files are flagged, not deleted.
Logged
Every file, every version, when and where.
EU-hosted
Hosted in the EU (Google Cloud, Finland).

Per company, then per project.

One setup fee per company, then a fixed monthly fee per active project. Finished projects can be archived at no cost. Ask for a quote.
