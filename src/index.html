Manual copying puts old drawings on site

Architects and engineers publish in Forma Data Management, part of the Autodesk Forma industry cloud (formerly Autodesk Construction Cloud, ACC) and increasingly the common data environment (CDE) owners require. Site work and quality control run in Procore, AjourBox or SharePoint. So someone copies every revision across by hand. It takes time every week, and one missed revision means building from an outdated drawing.

Set up once, synced from then on

  1. 1ConnectYour Autodesk admin adds Samofin Connector as a custom integration with read-only access.
  2. 2MapTogether we choose which Autodesk folders sync to which folders in your site system.
  3. 3ReviewBefore anything is copied, you review a dry run showing exactly what will be created.
  4. 4SyncNew versions are copied automatically, and every copy is logged.

Same folders, every version

A folder in Forma Data Management is mapped to a folder in the target system. Each new version is copied into it, and the log shows which version was copied, when, and where to.

Safeguards built in

One-way
Reads from the source, never writes to it.
Never deletes
Nothing is deleted in your site system. Files removed in Autodesk are flagged for review.
Versions, not copies
A new revision becomes a new version of the same file, so history stays in one place.
Traceable
An append-only log of every file and version: what was copied, when and where.
EU-hosted
Hosted in the EU (Google Cloud, Finland).

Questions and answers

Which file types are synced?
All of them. Every file in a mapped folder is copied as it is: PDF, DWG, IFC, RVT, Office files and anything else.
How fast does a new version arrive?
Within the hour. Mapped folders are checked for changes every 15 minutes by default.
What access does it need?
Read-only access to Forma Data Management, which your Autodesk account admin grants as a custom integration. In your site system, a dedicated service account with access only to the projects or sites you choose. It never writes to Autodesk and never deletes anything.
How long does setup take?
A few weeks from agreement to go-live. We set up the folder mapping with you, you review a dry run, and the connector then runs alongside your current process for one to two weeks before you switch over.
What happens when a drawing is revised?
The new revision is added as a new version of the same file in your site system, so the history is kept and nothing is duplicated. Older versions are never removed, and renamed or moved files are tracked rather than uploaded again.
Which systems does it support?
Forma Data Management (formerly Autodesk Docs, part of Autodesk Construction Cloud) as the source, and Procore, AjourBox and SharePoint as targets. One Autodesk project can feed several targets at once.
When can we start?
Now. Samofin Connector launches in 2027, and pilot customers are onboarded first and help shape what comes next.
